## GPU服务器租用到底租的是什么？

租的是一台装了 GPU 的云端服务器。云平台通过虚拟化技术把物理 GPU 映射成一个个实例，你选好 GPU 型号、CPU 内存配比和节点位置，几分钟就能拿到一台预装好驱动和深度学习环境的机器，训练、推理、渲染任务直接开跑。

有两种资源交付方式值得知道：**直通模式**把整块物理 GPU 独占给你，性能接近裸金属，适合正经训练；**分片模式**把一块卡切成几份共享，便宜，适合轻量推理和开发调试。部分平台还支持 MIG 硬件级切分——H100、H200、A100 这类卡可以切成最多 7 个隔离实例，给多租户推理用。

除了 AI，影视特效渲染、视频转码、分子动力学模拟、基因组分析这些任务同样靠 GPU 加速，思路一样：按项目周期开机器，跑完就释放。

为什么 A100 80G 能比 4090 贵近五倍？卡本身只是一部分。数据中心卡出厂价在 9,000 到 45,000 美元之间，消费级的 RTX 4090 是 1,800 美元；而且数据中心卡离开机房条件基本没法用——一个 8 卡节点要 6–10 千瓦供电、25°C 以下的进风温度和 100 Gbps 网络，托管机位的行情是每千瓦每月 200–600 美元。这些成本最后都摊进了你付的小时价。

贵得有理由的地方还有三处，这也是消费卡和数据中心卡在租用场景里的真实差别：

- **ECC 显存纠错**：多天连续训练中发生的位翻转会被自动检测修正；消费卡没有这个能力，错误会静默污染模型权重。
- **NVLink 互联**：8 卡 H100 节点靠 NVLink 能把 70B+ 参数的分布式训练当作一块卡来跑；没有 NVLink 的卡只能走 PCIe，集合通信慢 4–8 倍。
- **三档定位**：数据中心卡管集群级训练和在线服务，工作站卡（A6000 这类）管 24/7 的持续负载，消费卡管游戏加轻量 AI——租价基本就按这个梯度排。

一句话判断：出图、小模型推理，消费卡性价比最高；要跑多天不停的正式训练，数据中心的稳定性和纠错能力值这个钱。

## 按任务选档位：一张对号入座的清单

显存决定下限，任务类型决定要不要为数据中心卡掏钱。对照下面的档位选，基本不会错得太离谱：

1. **SD 出图、跑 demo、7B 级模型量化推理** → 24GB 消费卡（4090 档，行情每小时 1.65 元）。Ada/Blackwell 代的 4090、5090 有原生 FP8 推理路径，做推理吞吐并不虚。
2. **70B 模型 4-bit 推理、SDXL 训练、正经的 LoRA 微调** → 48GB 档（A6000、RTX 6000 Ada 这类工作站卡）。
3. **多天不停的正式训练** → 数据中心卡，ECC 和 NVLink 都要占。
4. **多租户推理服务** → 认准支持 MIG 的卡（H100/H200/A100），一块卡切几份给不同业务。
5. **只是写代码、调环境** → 先开无卡 CPU 模式，每小时不到两毛钱，等真正 run 模型时再开 GPU。

## 下单前要确认的几件事

把下面五条过一遍再付款，能省掉大部分事后麻烦。

**显存峰值先算够。** 模型权重只是底线，KV cache、激活值、框架开销都要吃显存。宁可留两成余量，也不要让任务在显存 99% 的位置反复重跑。

**长训练任务认准 ECC。** 12 小时以上的训练跑在无 ECC 的消费卡上，一次位翻转就可能让权重静默损坏，你还查不出原因。这也是很多正经训练任务会主动过滤消费卡的原因。

**用竞价实例就必须配检查点。** 竞价（抢占式）实例用的是平台闲置容量，折扣大，但平台可能随时回收。容错性强的批处理任务放心用；正经训练任务要把 checkpoint 存到持久化存储，中断后从最近的检查点续跑，而不是从头再来。

**数据和节点位置。** 推理服务选离用户近的节点；训练任务留意存储吞吐，本地 NVMe 延迟最低，海量数据集和检查点放对象存储。涉及合规的场景，直接选能满足数据主权要求的区域。

**自己买卡做“二房东”要另算账。** GeForce 的用户协议对数据中心用途有限制条款，消费卡风扇在 24/7 满载下 10–18 个月就到寿命。纯租用者不受影响，想规模化自建的人要把这两条算进风险。
